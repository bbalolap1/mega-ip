# IMPROVEMENTS APPLIED

These improvements change execution, not the creative concept.

## 1. Clear Version Boundary

Version 0.0 is limited to a working two-dimensional Streamlit prototype.

This prevents premature 3D development from obscuring the main goal.

## 2. Canon Protection

Alternative and experimental branches are stored separately and cannot overwrite canon.

## 3. Markdown Remains Authoritative

JSON and SQLite are treated only as generated or supporting representations.

The creator's Markdown lore remains the source of truth.

## 4. Unresolved Ideas Stay Unresolved

Codex is instructed to label missing details rather than inventing permanent lore.

## 5. Beginner-Readable Code

The code must use small modules, type hints, comments, straightforward names, and basic tests.

## 6. One Complete Narrative Proof

The first scene is fixed as Ordos' First Divine Decision.

This tests cosmology, character, philosophy, canon status, scene presentation, and branching without building the entire Omniverse.

## 7. No Conventional Game Mechanics

The prompt explicitly blocks unrelated RPG systems such as loot, leveling, currencies, quests, and win conditions.

## 8. Testable Completion

Codex must verify parsing, branch safety, application startup, and provide exact run instructions.
