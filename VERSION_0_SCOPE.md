# VERSION 0.0 SCOPE

## Purpose

Version 0.0 proves that the Mega IP Universe can be represented as editable Markdown and displayed through a visual narrative application.

## Included

- Markdown lore parsing
- YAML frontmatter
- universe overview
- Ordos timeline
- Ordos character page
- lore editing
- one scene viewer
- protected alternative branches
- simple local assets or placeholders
- local execution through Streamlit

## Not Included

- 3D rendering
- Minecraft integration
- online multiplayer
- autonomous AI characters
- procedural cities
- combat simulation
- full cosmology simulation
- complete faction behavior
- generated animation
- voice acting
- production-quality artwork
- mobile application
- cloud deployment

These are excluded to protect the main goal and keep Version 0.0 understandable and achievable.

## Version 0.0 Success Test

The prototype succeeds when the creator can:

1. open the application
2. view the universe foundation
3. inspect Ordos
4. follow the initial timeline
5. read the first scene
6. edit a Markdown lore file
7. create an alternative branch
8. confirm that canon remains unchanged
