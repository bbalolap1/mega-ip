# Mega IP Codex Version 0.0 Bundle

## Recommended Use

1. Create a new empty repository.
2. Copy all files from this bundle into the repository root.
3. Open the repository in Codex.
4. First tell Codex:

   `Read AGENTS.md and FOUNDATION.md. Do not write code yet. Summarize the Version 0.0 goal and identify any contradictions.`

5. Review the summary.
6. Then paste the contents of `CODEX_V0_BOOTSTRAP_PROMPT.md`.
7. Let Codex build Version 0.0.
8. Review all lore files before accepting them as canon.

- `FOUNDATION.md`: original foundation supplied by the creator
- `AGENTS.md`: persistent project rules
- `CODEX_V0_BOOTSTRAP_PROMPT.md`: main build instruction
- `VERSION_0_SCOPE.md`: boundaries for Version 0.0
